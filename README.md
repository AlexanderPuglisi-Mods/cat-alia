# Cat-Alia

![Cat-Alia](https://raw.githubusercontent.com/AlexanderPuglisi-Mods/cat-alia/main/images/catalogo.png)

A red-and-blue street brand from Catania, with the black cat and Mount Etna, for **skate.** with **ReSkate**: 3 new cosmetic items. No original item is replaced.

## Items

| Category | Items |
|---|---|
| Tops | Felpa Rossazzurra (hoodie) |
| Hats | Cappello (cap) · Berretto Rossazzurro (beanie) |

## Installation

- **ReSkate Launcher:** open **MODS** and install *Cat Alia*.
- **Manual:** extract the zip into its own folder inside the game's `Mods` folder (next to `Skate.exe`). Do not import it with Studio's *ADD .FBMOD*.

## Italiano

Brand catanese rossazzurro, con il gattino nero e l'Etna, per **skate.** con **ReSkate**: felpa, cappello e berretto, 3 capi nuovi, nessun capo originale sostituito. Si installa dalla pagina **MODS** del launcher di ReSkate, oppure estraendo lo zip in una cartella dentro `Mods`, accanto a `Skate.exe`.
